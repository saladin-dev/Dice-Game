# 🎲 Dice Roller Game (Python Edition)

Welcome to my text-based Dice Roller game built in Python!  
This project was created as a beginner-friendly way to practice Python fundamentals like loops, conditionals, user input, and working with random values.

---

## 🎮 Gameplay Overview

- Rolls two 12-sided dice each round.
- Displays each die with detailed ASCII art.
- Deducts 10 points per roll.
- Awards bonus points depending on the roll total.
- Game ends when points reach zero or player chooses to exit.

---

## 🧠 Features

- Dynamic ASCII art for dice values from 1 to 12.
- Clean, beginner-friendly Python code.
- Interactive loop with replay or exit option.
- Point tracking system with win/loss logic.

---

## 🛠 Technologies Used

- **Python 3**
- Standard Python library: `random`
